# Contributing

Thank you for wanting to contribute. Please follow these guidelines:

1. Fork the repository and create a branch for your change (feature or fix).
2. Write clear, focused commits and a descriptive PR title/body.
3. Add tests for new features or bug fixes when possible (pytest recommended).
4. Keep code style consistent; use meaningful names and small functions.
5. Run tests locally before opening a PR: `python -m pytest`.

Reporting issues

- Open an issue for bug reports or feature requests and include a minimal
  reproduction, environment details, and expected vs actual behavior.

Communicating

- Be respectful and patient in code review discussions. Maintain clear PR
  descriptions and link related issues.
