# Data Science Lab

[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE) [![CI](https://github.com/maxprime-create/data_science_lab/actions/workflows/ci.yml/badge.svg)](https://github.com/maxprime-create/data_science_lab/actions/workflows/ci.yml)

A collection of small, focused Python projects and scripts that demonstrate core programming skills and introductory data-science ideas.

## Quick start

1. Clone the repo:
```bash
git clone https://github.com/maxprime-create/data_science_lab.git
cd data_science_lab
```
2. Run a script with Python 3.9+:
```bash
python "movie ticket booking generator.py"
```
